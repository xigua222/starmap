# Privacy Policy for StarMap 

Effective Date: [2026-06-09]

StarMap (“the Extension”, “we”, “our”) is a browser new-tab productivity extension
that provides unified search, quick website access, AI prompt shortcuts, translation
shortcuts, local utility tools, wallpaper features, and optional local AI conversation
memory.

This Privacy Policy explains what data the Extension handles, how it is used, and how it
is shared. By using the Extension, you agree to the practices described below.

## 1. Single Purpose

StarMap has one single purpose: to help users search, navigate, organize, and reuse
personal browsing workflows from the new tab page and supported AI websites.

All permissions and data handling are used only to provide or improve this user-facing
purpose.

## 2. Data the Extension Handles

Depending on which features you use, the Extension may handle the following data:

- Extension settings and preferences, such as language, appearance, shortcuts, enabled
  tools, wallpaper settings, and blocked or hidden items.
- Browser bookmarks, used locally to show quick access shortcuts and matching suggestions.
- Browser history, used locally to show recent or frequently visited shortcuts and local
  search suggestions.
- User-entered search queries, prompts, URLs, text snippets, color values, units, numbers,
  or other tool inputs.
- Optional AI conversation records that the user manually saves or chooses to sync from
  supported AI websites.
- Optional context selections that the user chooses to reuse when asking AI services.
- Wallpaper cache data, thumbnails, and image metadata.
- Locally generated exports, such as JSON, Markdown, PDF, or archive files.
- Technical extension state, such as feature toggles, cache indexes, and local database
  metadata.

The Extension does not collect payment information, government identifiers, biometric
data, health data, or authentication credentials.

## 3. How Data Is Used

The Extension uses data only to provide and improve its disclosed features, including:

- Displaying the customized new tab page.
- Showing search, AI, translation, map, and website shortcut options.
- Showing local suggestions from bookmarks and browsing history.
- Saving user preferences between browser sessions.
- Saving and searching optional AI conversation memory locally.
- Reusing user-selected AI conversation context.
- Caching wallpapers and thumbnails for performance.
- Running local utility tools such as QR code generation, password generation, hash
  calculation, unit conversion, timezone conversion, zip code recognition, phone number
  recognition, and plate number recognition.
- Opening user-selected external websites or AI services.

The Extension does not use user data for advertising, credit eligibility, profiling,
or sale to data brokers.

## 4. Local Storage and Encryption

Most Extension data is stored locally in the user’s browser using extension storage,
localStorage, IndexedDB, or local database storage.

AI conversation memory is stored locally. If local encryption is enabled, conversation
data is protected using local AES encryption. The encryption key is kept locally in the
browser. If the user loses the key backup, previously encrypted records may become
unreadable.

Users may delete local data by using the Extension’s reset, clear-history, clear-AI-records,
or browser extension data removal features.

## 5. Data Sharing and Third-Party Services

StarMap does not operate a backend server that receives or stores user data.

However, when the user uses features that rely on external services, the relevant request
may be sent directly from the browser to that third party. Examples include:

- Search engines, AI websites, translation services, map services, or social websites
  chosen by the user.
- Public APIs for wallpaper images, artwork images, stock data, currency exchange rates,
  IP lookup, or similar user-facing tools.
- Supported AI websites when the user asks a question, enables prompt sending, saves a
  conversation, or chooses to attach saved context.

Third-party services process data according to their own privacy policies. StarMap 
does not control those third-party services.

The Extension does not sell, rent, or transfer user data to advertising networks, data
brokers, or other third parties for unrelated purposes.

## 6. Browser History and Bookmarks

Browser history and bookmarks are used only for user-facing features such as quick access,
recent sites, frequent sites, bookmarks, and local suggestions.

History and bookmark data are processed locally in the browser. They are not uploaded to
our servers, sold, or used for advertising.

## 7. AI Conversation Memory

If enabled by the user, StarMap  may save AI conversation content from supported AI
websites locally in the browser. This feature is intended to let users search, export,
and reuse their own AI conversations.

AI conversation data is not sent to us. If the user chooses to reuse a saved conversation
as context, that selected context may be sent to the AI website chosen by the user as part
of the user’s prompt workflow.

## 8. Remote Code

StarMap does not use remote code. All JavaScript, content scripts, background scripts,
and user interface code executed by the Extension are included in the extension package.

The Extension may fetch remote data or media, such as images, JSON API responses, stock
quotes, exchange rates, or IP lookup results. These resources are used as data or media
and are not loaded or executed as remote JavaScript or WebAssembly code.

## 9. Data Retention

Local data remains in the user’s browser until the user deletes it, resets Extension
settings, clears browser extension data, or uninstalls the Extension.

Data sent to third-party services is governed by those services’ own retention policies.

## 10. User Controls

Users can:

- Disable optional features in the Extension settings.
- Clear local query history.
- Clear locally saved AI conversation records.
- Reset all Extension settings.
- Delete Extension data through the browser.
- Uninstall the Extension at any time.

## 11. Limited Use Disclosure

The use of information received from Chrome extension APIs will adhere to the Chrome Web
Store User Data Policy, including the Limited Use requirements.

StarMap uses user data only to provide or improve its single purpose and user-facing
features. StarMap does not sell user data, does not transfer user data for advertising,
does not use user data for personalized or retargeted ads, and does not allow humans to
read user data except where required by law, security, or with the user’s explicit consent
for support.

## 12. Security

The Extension handles data locally where possible and uses HTTPS when communicating with
external services. Optional local encryption is available for AI conversation memory.

No method of storage or transmission is completely secure, but the Extension is designed
to minimize data transfer and keep user-controlled data local whenever possible.

## 13. Children’s Privacy

StarMap is not directed to children under 13 and does not knowingly collect personal
information from children.

## 14. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be reflected by
updating the effective date above.
